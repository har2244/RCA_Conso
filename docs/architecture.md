# Architecture Overview

The project structure is described in
[technical_architecture.md](technical_architecture.md). This document is kept
as a concise entry point for the original scaffold documentation.

The `src/rca_consolidator/` package separates the user interface, ingestion,
processing, validation, reporting, export, services, and utilities.
Configuration is centralized in the top-level `config/` package. The modules
are placeholders and intentionally contain no application behavior.

# RCA AI Handoff Pack

Copy these files into the root of your existing project and keep them in Git. They let Copilot, Antigravity, or another coding assistant recover project context without chat history.

Start every new AI session by sharing `AI_START_HERE.md`. After each completed implementation, update `docs/PROJECT_STATUS.md` and `docs/CHANGELOG.md`.

This pack reflects information verified on 23 November 2026. The full pytest suite passed 175 tests and Python compilation passed. Bucket validation and formatted Excel export are implemented.
